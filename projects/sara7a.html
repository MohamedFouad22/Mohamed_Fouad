Sara7a App
Backend

A robust and anonymous feedback system designed to facilitate honest communication. The backend focuses on identity protection, secure message routing, and seamless media handling. Built with professional validation standards and high-performance cloud storage integration for user profiles.

Technologies Used

Key Features

Anonymous Messaging

Advanced logic to ensure messages are sent without revealing sender identity while maintaining recipient privacy.

JWT Secured Authentication

Secure login and signup flow using JSON Web Tokens for stateless session management and route protection.

Schema Validation (JOI)

Rigid server-side validation for all incoming data to prevent NoSQL injection and ensure data integrity.

Cloudinary Media Integration

Seamless profile picture uploads and media management using Cloudinary API for fast and optimized delivery.

User Dashboard & Privacy

Features for users to view received messages, delete content, and manage their public profile visibility.
