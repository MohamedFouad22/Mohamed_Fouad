An advanced, modular E-Commerce backend RESTful API built with NestJS. Engineered for scalability and high performance, featuring complex catalog management, real-time inventory tracking, multi-tier user authorization, and automated order workflows using modern architectural patterns.

Key Features

Role-Based Authentication & Authorization

Secure JWT authentication with Guards and Custom Decorators supporting multi-role access management (Admin, Seller, Customer).

Advanced Catalog & Category Architecture

Nested category hierarchy, dynamic product brand management, stock management, and filtering/pagination support for large inventories.

Shopping Cart & Order Processing

Persistent cart management, coupon validation logic, subtotal recalculations, and structured order creation pipelines.

Data Integrity & Pre-Save Hooks

Mongoose pre-save middleware hooks for slug generation, bcrypt password hashing, and strict schema validation rules.

Modular NestJS Architecture

Clean code organization utilizing Dependency Injection, Services, Controllers, Custom DTOs, and global exception filters.
